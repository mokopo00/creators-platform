本ファイルは `CLAUDE.md` の補足です。機能要件・絶対ルール・セキュリティ・法務の詳細は `CLAUDE.md` を正とし、本ファイルでは **実装フェーズ（第7章）** と **受け入れ基準（第8章）** を定義します。
章番号は `CLAUDE.md` と `AUTONOMOUS_RUN.md` からの参照に合わせています。

## 7. 実装フェーズ（各フェーズ完了ごとに commit）

### Phase 0：基盤
- リポジトリ初期化、`README.md`、`.gitignore`、`.env.example`、ESLint・Prettier・TypeScript strict
- git の author 設定の確認（CLAUDE.md 2-2）
- CI（GitHub Actions：lint・型チェック・テスト・`npm audit`）
- `docs/` に `DECISIONS.md`、`TECH_DECISIONS.md`、`LEGAL_TODO.md`、`SECURITY.md` を作成
- `LICENSE` を作成（CLAUDE.md 3-6）

### Phase 1：デザインシステム
- 白ベースの Liquid Glass テーマ
- ガラスコンポーネント：Card、Button、Input、Modal、Tabs、Toast
- 共通アニメーション：フェード、stagger、ホバー、押下
- 全画面スケルトンコンポーネント（レイアウト同形状＋シマー）
- `prefers-reduced-motion` の対応、フォールバック背景

### Phase 2：認証
- Google OAuth（Authorization Code + PKCE、`state` 検証、`redirect_uri` 許可リスト）
- セッション管理（HttpOnly・Secure・SameSite=Lax、KV保存）、ログアウト
- 認可ミドルウェア（リソースごとの所有・参加チェック）
- テスト用モック認証：開発・テスト環境のみ有効。ステージング・本番では無効化する

### Phase 3：プロフィールと投稿
- クリエイター登録、プロフィール（ポートフォリオ表示）、テーマ変更
- 投稿の作成・編集・削除、R2 への署名付きアップロード、ハッシュタグ、分野タグ
- 二次創作禁止・AI補助申告の同意チェック
- 新着・おすすめのタイムライン

### Phase 4：依頼と決済
- 依頼ボタン、リクエストページ（料金表・サンプル・注意事項・減額条件と金額例）
- 依頼テンプレート、依頼チャット（Durable Objects / WebSocket）
- Stripe Checkout（テストモード）による前払い
- Stripe Connect（Separate charges and transfers）による、双方の受取承認後の送金
- 納期管理、Cron による遅延判定と減額（CLAUDE.md 3-5 に従う）
- 依頼者の全額返金キャンセル、正当理由による減額停止フラグ

### Phase 5：ランキング・通知・検索
- 週間・月間・ハッシュタグ別・分野別ランキング（Cron で集計）
- アプリ内通知（新作、依頼の進捗）
- お気に入り（無制限）、保存フォルダ
- 検索（D1 FTS5、入力エスケープ済み）

### Phase 6：Workers AI 機能
- AIタグ生成（候補提案、ユーザーが確定）
- AI翻訳（投稿・プロフィール・チャット）
- AIおすすめ検索
- 依頼テンプレート補助のチャットボット、よくある質問への回答
- AI処理のタイムアウト、失敗時フォールバック（画面を壊さずメッセージ表示）、レート制限
- 使用モデルIDと確認日を `docs/TECH_DECISIONS.md` に記録

### Phase 7：分析・プレミアム・その他（枠組みのみ可）
- 詳細分析（閲覧・保存・依頼の推移）
- プレミアム会員の状態管理（決済はテストモード）
- 上位表示予約・広告（プロモーション）の枠組み
- デジタル販売の枠組み（手数料15%の設定値のみでよい）
- 設計のみ・実装しないもの：本人確認、企業向けポートフォリオ、企業連携

### Phase 8：法務ページ・セキュリティ確認
- 利用規約、プライバシーポリシー、特定商取引法に基づく表記（事業者情報は環境変数）
- 通報フォーム、著作権削除申立フロー、アカウント削除
- 年齢確認の仕組み（有償依頼は18歳以上）の記録
- セキュリティヘッダー、CSP、レート制限の確認
- `git grep` による個人情報・秘密情報の残存チェック

### Phase 9：テスト・公開（段階的）
- **9-1 テスト**：Vitest（単体）と Playwright（E2E）。第8章の全項目を自動化して合格させる
- **9-2 GitHub Public 公開**：CLAUDE.md 8-5 の手順に従う
- **9-3 Cloudflare ステージング公開**：CLAUDE.md 8-6 の手順に従う。テストデータのみ
- **9-4 本番公開の停止点**：本番公開は行わない。CLAUDE.md 8-4 の条件が揃うまで実施せず、準備状況を報告して終了する

## 8. 受け入れ基準（すべて満たすこと）

### 認証・アクセス
- [ ] Google ログインのみで登録・ログインできる（他の認証手段が存在しない）
- [ ] 他ユーザーの投稿・依頼を編集・閲覧できない（IDOR）ことを自動テストで確認する
- [ ] SQLインジェクションを含む入力でエラーにならず、データが漏れないことを自動テストで確認する

### 画面・UI
- [ ] すべての主要ページで全画面スケルトンが表示され、データ取得後に切り替わる
- [ ] 白ベースの Liquid Glass UI で、主要要素にガラス効果とアニメーションがある
- [ ] `prefers-reduced-motion` 有効時にアニメーションが最小化される
- [ ] モバイルとPCで、タブバーとサイドバーが正しく切り替わる

### 投稿・探索
- [ ] 作品投稿（画像）→ プロフィール表示 → 新着・おすすめへの表示が通る
- [ ] ハッシュタグ・分野で絞り込みでき、週間ランキングが表示される

### 依頼・決済
- [ ] 依頼ボタン → リクエストページ → 依頼作成 → チャット送信が通る
- [ ] テスト用決済（Stripe テストモード）で前払いができ、承認後に送金状態へ遷移する
- [ ] 遅延時、1日ごとに受取額の5%が減額され、合計が50%で止まることを自動テストで確認する
- [ ] 遅延時に依頼者が全額返金でキャンセルでき、クリエイターへの支払いが発生しないことを自動テストで確認する
- [ ] 正当な理由の遅延は減額されないことを自動テストで確認する

### AI
- [ ] Workers AI による翻訳・タグ生成が動作し、失敗時は画面が壊れずにメッセージが出る

### 法務・リポジトリ
- [ ] 利用規約・プライバシーポリシー・特定商取引法に基づく表記のページが存在し、リンクされている
- [ ] `LICENSE` が存在し、すべての権利を留保する内容で、第三者への利用許諾を含まない
- [ ] `docs/LEGAL_TODO.md` に法的確認項目が記録されている
- [ ] 個人情報（実在の氏名・メール等）がリポジトリ内に存在しない（`git grep` で確認）
- [ ] git の author に個人のメールアドレスが含まれていない
- [ ] 秘密情報がコミットされていない（`.env` 等が追跡されていない）

### 公開
- [ ] GitHub に Public で公開されている
- [ ] Cloudflare のステージングURLで動作し、スモークテストが通る
- [ ] 本番公開は未実施で、停止点の準備状況が報告されている
